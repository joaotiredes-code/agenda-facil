# 8. Roteiro dos Vídeos

## Vídeo 1 — Solução em funcionamento (até 5 min na Situação 3; mín. 5 min narrado na Situação 2 — confira com seu tutor qual vale para cada entrega)
| Tempo | Conteúdo |
|-------|----------|
| 0:00–0:30 | Apresentação: seu nome, o problema (agendamentos em papel geram conflito) e o objetivo do sistema |
| 0:30–1:30 | Arquitetura MVC: mostrar as pastas `models`, `views`, `controllers` e explicar em uma frase cada |
| 1:30–2:15 | Banco de dados: mostrar `schema.sql`, tabelas e relacionamentos |
| 2:15–4:00 | Demonstração: cadastrar serviço, profissional, cliente → agendar → mostrar horário que some da lista → tentar conflito → cancelar |
| 4:00–4:40 | Testes: executar `python -m unittest discover -s tests -t . -v` e mostrar "OK" |
| 4:40–5:00 | Encerramento: GitHub, próximos passos |

## Vídeo 2 — Mudanças adotadas após os testes (Situação 3)
| Tempo | Conteúdo |
|-------|----------|
| 0:00–0:30 | Como foi o teste (5 testadores, formulário) |
| 0:30–2:30 | Para cada problema/sugestão: mostrar o "antes", a correção e o "depois" |
| 2:30–3:00 | O que ficou para versões futuras e o que aprendeu |

## Dicas
- Grave a tela com OBS Studio, Zoom ou Google Meet e narre com calma.
- Teste o áudio antes. Feche abas e notificações.
- Dados de exemplo: `flask --app run seed`.
